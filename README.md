# Control IoT de humedad y temperatura en invernaderos

## Descripción del proyecto

El proyecto consiste en desarrollar un sistema de monitoreo IoT para registrar y visualizar las condiciones de humedad y temperatura en cultivos de invernadero, tomando como referencia inicial las plántulas de tomate.

Como parte del proyecto, se propone desarrollar y caracterizar un sensor óptico de humedad que utilice la reflexión de un haz infrarrojo sobre el sustrato. Se busca establecer una relación entre la luz reflejada y el nivel de humedad presente, para posteriormente comparar su comportamiento con el de sensores de humedad comerciales.

El sistema permitirá recopilar información de manera continua y centralizada, con el propósito de facilitar el seguimiento de las condiciones del cultivo y apoyar la toma de decisiones.

## Oportunidad del proyecto

La oportunidad surge de la necesidad de contar con herramientas que permitan monitorear individualmente las condiciones de humedad y temperatura de las plantas en invernaderos.

Se plantea explorar una alternativa de medición óptica menos invasiva, así como integrar un sistema IoT para almacenar y visualizar los datos obtenidos.
